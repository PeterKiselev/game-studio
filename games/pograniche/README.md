# Пограничье

Вертикальный срез браузерной RPG: пролог и две сюжетные главы с тактическими боями, заранее показанными намерениями противников и постоянным развитием героя.

В срез уже входят:

- три главы, девять обязательных противников и восемь необязательных зверей с разными навыками;
- семь тактических действий: атака, финт, тяжёлый удар, блок, уклонение, зелье и полынная настойка;
- нарисованные персонажи и противники, а также видимые на герое варианты оружия и брони;
- шесть этапов выбора походного комплекта и семь вариантов оружия и брони, меняющих характеристики, правила боя и внешний вид;
- три карты с развилками между запасами, торговлей, настойками, лечением и боковыми звериными тропами;
- глава II «Чёрный колокол»: Фонарщик-косарь, Железный палач, Моровой лекарь, Кованый вепрь и Воронья стая;
- постоянный инвентарь и выбор стартового комплекта между походами;
- звериные метки и три постоянные ветки развития: сила, живучесть и запасы;
- город после первого завершённого похода: кузница, лавка зелья и настойки, скупщик посылки из погребов и три боевых поручения;
- две Печати привратника за завершённые походы: они расширяют стартовый кисет настоек без второй валюты;
- перенос здоровья и зелий через весь поход, передышка после обязательных боёв и честный риск звериных троп;
- сохранение текущего боя, его стартового чекпоинта, этапа похода и выбранной экипировки;
- повтор проигранного боя с ресурсами на момент входа, безопасное прерывание непроходимого похода и новый поход после победы.

## Запуск

Из корня `game-studio`:

```bash
npm run dev:pograniche
```

Локальный адрес: <http://localhost:5175/>.

## Проверка и сборка

```bash
npm test
npm run typecheck
npm run build:pograniche:web
npm run build:pograniche:vk
```

Это проверяемый вертикальный срез, а не версия для публикации. Следующий этап — измерить, хочется ли возвращаться в город ради закалки, настойки, сдачи посылки и поручений после главы «Чёрный колокол». До подтверждения интереса платежи не подключаются.
