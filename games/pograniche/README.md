# Пограничье

Первый вертикальный срез браузерной RPG: короткий поход из трёх тактических боёв с заранее показанными намерениями противников.

В срез уже входят:

- три обязательных противника и четыре необязательных зверя с разными навыками;
- шесть тактических действий: атака, финт, тяжёлый удар, блок, уклонение и зелье;
- нарисованные персонажи и противники, а также видимые на герое варианты оружия и брони;
- два выбора добычи, реально меняющие характеристики и внешний вид;
- карта похода с развилкой между дополнительным зельем и засадой, а также боковыми звериными тропами;
- постоянный инвентарь и выбор стартового комплекта между походами;
- звериные метки и три постоянные ветки развития: сила, живучесть и запасы;
- перенос здоровья и зелий через весь поход, передышка после обязательных боёв и честный риск звериных троп;
- сохранение текущего боя, его стартового чекпоинта, этапа похода и выбранной экипировки;
- повтор проигранного боя с ресурсами на момент входа, безопасное прерывание непроходимого похода и новый поход после победы.

## Запуск

Из корня `game-studio`:

```bash
npm run dev:pograniche
```

Локальный адрес: <http://localhost:5175/>.

## Проверка и сборка

```bash
npm test
npm run typecheck
npm run build:pograniche:web
npm run build:pograniche:vk
```

Это проверяемый вертикальный срез, а не версия для публикации. Следующий этап — расширить первый поход событиями и расходниками, добавить награду за его завершение и начать собирать полноценную первую главу. До подтверждения интереса игрока платежи не подключаются.
