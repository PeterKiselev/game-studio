# Game Studio — правила проекта

Этот файл читается в начале каждой сессии. Он держит суть проекта при смене
контекста и при переключении между моделями. Правила ниже обязательны:
если предлагаемое решение им противоречит — надо менять решение или явно
менять этот файл, но не молча отступать от него.

---

## 1. Что мы строим

Конвейер браузерных HTML5-игр. Не «одна игра», а **общее ядро + серия игр**,
которые выходят с одной кодовой базы сразу на несколько площадок.

Цель на полгода: 15–20 классических игр (крестики-нолики, судоку, пасьянсы,
маджонг, морской бой, дурак, нарды, шашки, домино, три в ряд, слова) на
Яндекс Играх, VK Mini Apps, Одноклассниках, дальше Telegram и CrazyGames.

**Главная метрика — не количество релизов, а удержание.** Целевые ворота:
D1 > 35%, средняя сессия > 6 минут. Пять игр с возвратом зарабатывают больше,
чем пятьдесят одноразовых.

## 2. Стек и структура

- Node 20, **npm workspaces** (не pnpm — его нет в окружении), TypeScript strict, Vite.
- Никаких игровых движков по умолчанию. Настольные и карточные игры — на DOM
  и CSS: бесплатно получаем фокус с клавиатуры, доступность, ретину и нулевой вес.
  Canvas/Pixi подключаем только там, где DOM реально не тянет (три в ряд, аркады).

```
packages/
  platform/   единый фасад IPlatform + адаптеры площадок + политика рекламы + сейвы
  rules/      чистые правила игр: ни DOM, ни таймеров, ни сети. Покрыты тестами
  ui/         дизайн-система: токены, кнопки, диалоги, тема, тактильность
  game-kit/   каркас запуска игры: boot, ready, раунды, автосейв, пауза на рекламу
games/
  <игра>/     тонкий пакет: сцена, контент, настройки. Цель 500–1500 строк
```

Зависимости идут строго вниз: `games → game-kit → ui/platform → rules`.
Обратных импортов нет. `rules` не зависит ни от чего.

## 3. Незыблемые правила

1. **Игра никогда не импортирует SDK площадки.** Только `IPlatform`. Любая
   новая площадка — это новый файл в `packages/platform/src/adapters/`, и
   ни одной правки в играх. Если хочется дёрнуть `YaGames` или `vkBridge`
   из игры — значит, в фасаде не хватает метода; добавляй метод в фасад.
2. **Перед показом любой кнопки проверяй `platform.caps`.** Площадка может
   не уметь rewarded, покупки, лидерборды. Игра не падает и не показывает
   мёртвых кнопок — она их скрывает.
3. **Правила игры — чистая функция.** Ходы иммутабельны (`play()` возвращает
   новое состояние). Никакого `Math.random()` без переданного сида. Это то,
   что позволит переиспользовать `rules` на сервере для сетевых партий.
4. **Реклама только через `AdManager`.** Прямой вызов `platform.ads.*` из
   игры запрещён: `AdManager` держит частотные лимиты, ставит паузу геймплея
   и глушит звук. Забыть об этом в одной игре из двадцати — вопрос времени.
5. **`app.ready()` вызывается, когда экран отрисован и по нему можно кликать.**
   Не раньше. Яндекс считает время до `ready()` временем загрузки.
6. **Никаких цветов в играх.** Только токены из `@studio/ui`. Обе темы
   (светлая и тёмная) обязательны, `data-theme` может отсутствовать —
   тогда работает `prefers-color-scheme`.

---

## 4. Политика рекламы (защита удержания)

Зашита в `packages/platform/src/ads-policy.ts`, менять только осознанно.

- Interstitial: не раньше 90 секунд сессии **и** не раньше 2 законченных
  партий, минимум 180 секунд между показами, максимум 8 за сессию.
- Rewarded: без ограничений по частоте, но только там, где игрок правда
  хочет награду — отмена хода после проигрыша, подсказка, продолжение.
  Игрок всегда заранее видит, что получит.
- Никогда: реклама до первой партии, реклама вместо кнопки «играть»,
  автоплей со звуком.
- `placement` в `rewarded(placement)` — это ключ аналитики. Разные строки
  для разных предложений, иначе не понять, что работает.

## 5. Планка интерфейса

Это то, чем мы отличаемся от конкурентов в нише. Проверяется перед релизом.

- Первый экран < 2 с на 4G, играбельно < 3 с. Бюджет первого чанка 300 КБ.
- 60 fps на пятилетнем телефоне. Ноль сдвигов вёрстки при загрузке.
- Портретная раскладка под одну руку, управление в нижней трети экрана.
- Зона нажатия >= 44 px. Автосохранение после каждого действия.
- Отмена хода везде, где это не ломает правила.
- Фигуры и масти различаются **формой**, а не только цветом (дальтонизм).
- Звук по умолчанию выключен на первом запуске.
- Экран «Продолжить» вместо главного меню, если партия не закончена.
- Никаких фальшивых «1234 игрока онлайн» и прочих обманок.

## 6. Площадки: порядок и особенности

| Площадка | Статус | Что помнить |
|---|---|---|
| Яндекс Игры | старт | РСЯ обязательна. `LoadingAPI.ready()`, `GameplayAPI.start/stop()`. Есть sticky-баннер, облачные сейвы, лидерборды |
| VK Mini Apps (Direct Games) | старт | vk-bridge. Нет sticky-баннера, только полноэкранные форматы. Есть покупки и шеринг. **Не путать с VK Play** — та про PC-каталог и облачный гейминг |
| Одноклассники | старт | Тот же vk-bridge, тот же адаптер. Демография идеальна под классику |
| Telegram Mini Apps | волна 2 | Нужен бот и серверная валидация initData. Реклама от сторонних сетей, покупки за Stars |
| CrazyGames | волна 2 | 60% с рекламы, 70% с покупок, бонус за 2 месяца эксклюзива. Нужна английская локализация |
| Poki | волна 3 | Кураторский отбор, плейтесты. 50/50, но 100% с собственного трафика |
| Playgama Bridge / GamePush | инструмент | Не витрина, а слой дистрибуции. Использовать как *реализацию* под нашим фасадом, не как замену ему |

Сборка: `npm run build:yandex`, `build:vk`, `build:web`. Режим Vite задаёт
`__PLATFORM__`; адаптеры лежат в ленивых чанках, поэтому лишний SDK
никогда не скачивается игроком.

## 7. Юридическое

- **Названия защищены, механики — нет.** Не используем «Тетрис», «Монополия»,
  UNO, Scrabble ни в названии, ни в оформлении, ни в описании. Наши падающие
  фигуры называются «Блоки», со своим артом и палитрой.
- Каждое название проверяем до релиза, а не после жалобы.

### Платёжные дороги

Доступны обе, каждый канал заранее приписан к своей:

- **Российская** — самозанятость (6%). Яндекс Игры, VK, OK, Дзен.
- **Международная** — грузинский счёт TBC: мультивалютный IBAN принимает SWIFT
  (CrazyGames с порогом €100, Poki), карта Visa/MC подключается к Payoneer и Wise.
  Стоит посчитать грузинское ИП со статусом малого бизнеса — 1% с оборота.

VPN решает доступ к интерфейсу, но не выплаты: площадки определяют страну по
документам, налоговой форме и стране банка. Регистрируемся на реальную
юрисдикцию, иначе заморозка баланса приходит ровно тогда, когда на нём
накопилось что-то заметное.

## 8. Как добавить новую игру

1. `packages/rules/src/<игра>.ts` — чистые правила + тесты в `packages/rules/test/`.
   Сначала тесты проходят, потом всё остальное.
2. `games/<игра>/` — копия структуры `games/gomoku`: `package.json`,
   `index.html`, `vite.config.ts`, `src/main.ts`, `src/style.css`.
3. Запуск через `GameApp.boot({ gameId, defaults })`. `gameId` — ключ сейва,
   **после релиза не менять никогда**.
4. Всё общее, что понадобилось второй раз, переезжает в `game-kit` или `ui`.
   Копипаста между играми — сигнал, что чего-то не хватает в общих пакетах.

## 9. Распределение по моделям

Проект ведётся в Claude Code, экономим осознанно:

- **Opus** — проектирование абстракций и всё, что потом дорого менять:
  `platform`, `game-kit`, `ui`, движок карт, сетевой сервер, разбор просевших метрик.
- **Sonnet** — работа по накатанному: новые игры поверх готового ядра, вёрстка
  экранов, локализация, тесты, багфиксы, скрипты сборки.

Правило: если задача создаёт новый интерфейс, которым будут пользоваться другие
пакеты — это Opus. Если задача пользуется существующим интерфейсом — Sonnet.

## 10. Команды

```bash
npm install          # один раз, из корня
npm run dev          # локальный запуск игры gomoku
npm test             # тесты правил
npm run typecheck    # строгая проверка типов по всему монорепо
npm run build:yandex # сборка под Яндекс в games/gomoku/dist/yandex
npm run build:vk     # сборка под VK
```
