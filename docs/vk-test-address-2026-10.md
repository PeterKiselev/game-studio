# Тестовый адрес для App ID 54788542 без изменения основного размещения

Дата: 7 октября 2026. Назначение: открыть сборку с диагностикой
(`release/sudoku-vk.zip`, `?diag=1`) внутри настоящего VK для существующего
приложения, **не меняя** поле «URL» в «Размещении» и не публикуя сборку на
основном адресе. Я ничего не загружал и в кабинет не заходил — документ
составлен по официальной документации VK; что из описанного есть именно в

## 1. Что говорит документация VK (прочитано 07.10.2026)

Источники: [Настройки](https://dev.vk.com/ru/mini-apps/management/settings),
[Размещение](https://dev.vk.com/ru/mini-apps/settings/general/placement),
[Тестовые группы](https://dev.vk.com/ru/mini-apps/settings/test-groups),
[Тестирование (старая панель)](https://dev.vk.com/ru/mini-apps/management/testing),
[Хостинг статики](https://dev.vk.com/ru/mini-apps/development/hosting).

Описаны два механизма, оба оставляют основной URL нетронутым:

| Механизм | Где | Кому виден тестовый адрес | Главное |
|----------|-----|---------------------------|---------|
| **Тестовая группа** | левое меню приложения → «Тестовые группы» (в старой панели: «Редактировать» → «Тестирование») | Только участникам группы (не обязательно администраторам). | У каждой группы свой URL и выбранные платформы; параметры передаются в URL после `?`. Основное «Размещение» не затрагивается. |
| **Режим разработки** | «Размещение» → у платформы переключатель и поле «Режим разработки» | Только администраторам приложения. | Для остальных пользователей приложение «продолжит открываться по URL». Заполняется поле режима разработки, поле «URL» не трогается. |

Порядок выбора адреса при запуске администратором (оба источника сходятся):
1) URL тестовой группы, если вы в группе; 2) URL режима разработки, если
включён для платформы запуска; 3) основной «URL».

Ограничения из документации: до 25 групп на приложение; пользователь — только
в одной группе; в группу добавляются только пользователи ВКонтакте; название
группы до 48 символов; создавать группы может создатель приложения или
администратор с полным доступом; платформы группы — «Android и iOS», `vk.com`,
`m.vk.com` (хотя бы одна).

**Для Одноклассников:** документация «Размещение» сообщает, что при состоянии
«Включено» приложение в ОК доступно только создателю до прохождения модерации.
Тестовые группы — только для пользователей ВКонтакте, поэтому **через группу
проверить ОК нельзя**; как открыть тестовый адрес в ОК, документация не
говорит — неизвестно.

## 2. Что нельзя считать известным

- Есть ли в вашем кабинете пункты «Тестовые группы» / «Режим разработки» и
  как именно они выглядят (в документации описаны и новая, и старая панели).
- Влияет ли текущее состояние приложения (на модерации / отклонено / отключено)
  на работу тестового адреса. Документация этого не говорит.
- Где разместить тестовую сборку (см. §3): не проверено ни одним запуском.

## 3. Где взять HTTPS-адрес сборки (нужен до шага 3)

Адрес должен отдавать содержимое `release/sudoku-vk.zip` по HTTPS и **не быть**
основным адресом `…/sudoku/vk/`.

| Вариант | Статус |
|---------|--------|
| Любой ваш HTTPS-хостинг статики | Работает по документации; есть ли у вас такой — не знаю. |
| Хостинг VK (`vk-miniapps-deploy`) | **Не рекомендую.** По `CLAUDE.md` этот инструмент на этой машине не проходит авторизацию VK ID (`invalid device_id`, затем `auth … not approved yet`). Кроме того, при загрузке он сам предлагает обновить **prod URL** — на этот вопрос пришлось бы отвечать «нет». |
| VK Tunnel (`vk-tunnel`) | **Не рекомендую**: та же запись в `CLAUDE.md` — не авторизуется. |
| Cloudflare-туннель | **Не работает** на этой машине (`CLAUDE.md`). |
| Другой путь на GitHub Pages | Основной адрес не меняется, но это **публичная выкладка** и требует `push` (деплой идёт на каждый push в master). Нужно отдельное решение Codex/владельца; я не делаю. |
| Отдельный репозиторий GitHub Pages только для теста | Не затрагивает основной сайт; создаёт владелец. Не проверено. |

## 4. Инструкция (владелец; я в кабинет не захожу)

**Шаг 1 — выяснить, что есть в кабинете. Ничего не менять.**
Откройте «Мои приложения» → приложение «Академия Sudoku» (App ID 54788542) →
откройте его настройки. Выпишите (или сфотографируйте) названия пунктов
левого меню. Нужно знать, есть ли «Тестовые группы» и в «Размещении» — «Режим
разработки». Пришлите скриншот меню; не присылайте ключи («Защищённый ключ»,
«Сервисный ключ») — они на странице «Настройки» и в чат не нужны.

**Шаг 2 — выбрать механизм по тому, что нашлось.**
- Есть «Тестовые группы» → способ А (предпочтительный: «Размещение» вообще не
  открывается).
- Нет групп, но в «Размещении» есть «Режим разработки» → способ Б.
- Нет ни того ни другого → остановиться и прислать скриншот; запасной путь —
  отдельное тестовое приложение (создаётся в списке приложений заново; его
  App ID будет другим, поэтому проверка рекламы там годится, но отдельное
  приложение отправлять на модерацию не нужно).

**Шаг 3А — тестовая группа.**
1. «Тестовые группы» → «Создать группу».
2. Название, например `diag` (до 48 символов).
3. URL: `<адрес тестовой сборки>/?diag=1` — точное значение `?diag=1`
   обязательно, иначе панели диагностики не будет. Адрес должен быть
   https и вести на **тестовую** сборку, не на основной.
4. Платформы: только те, которые будете проверять (десктоп — `vk.com`;
   телефон — «Android и iOS» и/или `m.vk.com`). Платформы, которые не
   отмечены, остаются на основном URL.
5. Участники: только вы (и тестировщик, если есть). Пользователь может быть
   только в одной группе — если вы уже в другой, сначала выйдите из неё или
   используйте другой аккаунт.
6. Сохранить. Основной URL в «Размещении» **не открывать и не менять**.

**Шаг 3Б — режим разработки (если групп нет).**
В «Размещении» у нужной платформы включите «Режим разработки» и впишите
`<адрес тестовой сборки>/?diag=1`. Поле «URL» оставьте как есть. Тестовый
адрес увидят только администраторы. Это правка страницы «Размещение»,
поэтому делайте её последней осознанно и запишите прежнее состояние
переключателя, чтобы вернуть.

**Шаг 4 — проверить, что основной адрес цел.**
Откройте приложение из **другого** аккаунта, который не в группе и не
администратор (или в приватном окне без входа, если VK позволяет), и убедитесь,
что панели диагностики нет и игра обычная. Из вашего аккаунта по ссылке
`https://vk.com/app54788542` должна появиться зелёная панель внизу. Если
панель видят все, значит изменился основной адрес — откатите (шаг 5)
и пришлите скриншот.

**Шаг 5 — откат после проверки.**
Группа: «Тестовые группы» → навести на группу → «Удалить» → подтвердить.
Режим разработки: выключить переключатель (и вернуть прежнее значение поля,
если оно было). Основное «Размещение» при этом не менялось.

Дальше — шаги проверки рекламы в `docs/vk-ads-check-2026-10.md`.

## 5. Риски и что подтвердить после запуска

- Первый запуск — единственное, что покажет, подхватил ли VK тестовый URL
  вместе с `?diag=1`; в журнале диагностики в первой строке видны имена
  параметров запуска.
- Если группа создана, но панели нет: проверьте платформу группы (запуск с
  другой платформы идёт на основной URL), участие в другой группе, опечатку в
  URL (нужен точный `?diag=1`).
- Ничего из этого документа не выполнялось: ни загрузка, ни правка кабинета,
  ни push.
