# «Дачные тайны» в ОК: изолированная тестовая сборка и проверка режима разработки

Дата: 14 октября 2026. **Подготовлено, ничего не выполнено:** ни выкладки, ни push, ни правок
кабинета, ни платежей. Работа подмены адреса в ОК **не подтверждена**, пока не будет живого
запуска с маркером на экране.

## 1. Что сказала поддержка VK (обращение по ОК, агент #14576)

Направили на актуальные разделы: «Публикация в Одноклассниках» (`dev.vk.com/ru/ok/publishing`) и
«Размещение» (`dev.vk.com/ru/games/settings/general/placement`). Из присланного текста:

- «Размещение» описано **для обеих площадок** — ВКонтакте и Одноклассников.
- «Режим разработки»: адрес в этом поле получают **все администраторы** игры; «для остальных
  пользователей игра продолжит открываться по URL, для них подмены не произойдёт».
- Порядок выбора адреса для администратора: **тестовая группа → режим разработки → URL**.
- До модерации в ОК игру может открыть создатель (и администраторы с правом «Тестирование»).

Это сильнее прежнего вывода в `docs/vk-test-address-2026-10.md` («как открыть тестовый адрес в ОК,
документация не говорит»). Но ответ поддержки — ссылка на документацию, а не подтверждение для
нашего приложения. **Подтверждением будет только маркер тестовой сборки на экране в настоящем ОК.**

Важные следствия:
- Режим разработки включается **по платформам** (Web, мобильная версия сайта, мобильное
  приложение). Проверяем только Web — остальные платформы остаются на основном URL.
- Режим разработки действует для **всех администраторов и во ВКонтакте тоже**: открыв игру на
  vk.com с компьютера, вы (и другие администраторы) тоже увидите тестовую сборку. Обычные игроки —
  нет.
- Тестовая группа приоритетнее режима разработки. Если вы состоите в тестовой группе с платформой
  `vk.com`, во ВКонтакте вы получите адрес группы, а не режима разработки. Группы — только для
  пользователей ВКонтакте; как они ведут себя при запуске в ОК, документация не говорит.

## 2. Тестовая сборка (готова локально)

```
npm run build:dachnye-tainy:oktest
```

- Результат: `games/dachnye-tainy/dist/ok-test/` (в git не попадает): `index.html`, `assets/`,
  `robots.txt`, `version.txt`.
- VK-сборка (тот же адаптер, что для ОК) с полосой сверху:
  **«ТЕСТ ОК · 2026-10-14 · 4d423a5 · клиент: ok · платформа: desktop_web»** — дата и коммит
  сборки, затем значения двух параметров запуска. `клиент: ok` — значит, игру открыли именно
  Одноклассники; `клиент: —` — ВКонтакте или обычный браузер. Подпись запуска, id пользователя и
  прочие параметры не выводятся. Заголовок вкладки — «[ТЕСТ] Дачные тайны».
- **Без платежей:** адрес платёжного сервера не задан, магазин в ОК скрыт — как в опубликованной
  версии. Локальный учёт статистики выключен. Закрыта от поиска (`noindex`, `robots.txt`).
- Если в рабочей копии были незакоммиченные изменения, в маркере будет «+изм» — для проверки в ОК
  лучше собирать из чистого коммита.
- Содержит **все локальные изменения**, которых нет у игроков (глава 1, дела дня). Видеть их будут
  только администраторы. Если нужна проверка ровно опубликованной версии — собрать из её коммита
  (отдельное решение).
- Проверено в браузере с заглушкой VK Bridge (`tools/playtest-oktest.cjs`): маркер виден и не
  мешает нажатиям, в ОК нет магазина, ни одного запроса на сторонние адреса, 360 px без
  горизонтальной прокрутки; обычная VK-сборка маркера не содержит. **Это не заменяет живой запуск.**

## 3. Где разместить по HTTPS, не трогая боевые игры

| Вариант | Оценка |
|---------|--------|
| **Отдельный публичный репозиторий GitHub только для теста** (например `dachnye-tainy-oktest`), GitHub Pages из ветки `main`, корень | **Рекомендую.** Адрес вида `https://peterkiselev.github.io/dachnye-tainy-oktest/`. Основной репозиторий, его workflow и все боевые адреса не затрагиваются. Файлы `dist/ok-test/` загружаются в новый репозиторий через веб-интерфейс GitHub («Add file → Upload files») — без push из основного репозитория. Бесплатно. Создаёт владелец. |
| Подпапка на текущем GitHub Pages (`…/game-studio/dachnye-tainy/ok-test/`) | **Нельзя сейчас.** Публикация идёт на каждый push в `master`, а локальный `master` впереди опубликованного на десятки коммитов (глава, дела дня, учёт). Push выложил бы игрокам всё это разом. |
| Хостинг VK (`vk-miniapps-deploy`), VK Tunnel, Cloudflare-туннель | Не работают на этой машине (`CLAUDE.md`); `vk-miniapps-deploy` к тому же предлагает обновить prod URL. |
| Cloudflare Pages / другой хостинг | Возможно, но новый сервис и учётная запись — отдельное решение. |

Оговорки к рекомендуемому варианту: адрес публичный — его может открыть любой, у кого есть ссылка
(тестовая сборка не секретна; платежей и ключей в ней нет). Репозиторий после проверки можно
удалить или сделать Pages выключенными.

## 4. Инструкция проверки (владелец; я в кабинет не захожу)

**Шаг 0 — сейчас, ничего не меняя.** Откройте приложение «Дачные тайны» (App ID 54767366) →
«Размещение» → блок **Web**. Пришлите скриншот полей **URL** и **Режим разработки** (включён ли
переключатель и что в поле). Ключи («Защищённый ключ», «Сервисный ключ») не показывайте. Запишите
прежнее состояние — понадобится для отката. Заодно проверьте раздел «Тестовые группы»: состоите ли
вы в какой-нибудь группе.

**Шаг 1 — сборка.** `npm run build:dachnye-tainy:oktest` из чистого коммита (без «+изм» в маркере).
Записать строку маркера из `version.txt`.

**Шаг 2 — размещение** (после решения по §3). Залить содержимое `dist/ok-test/` по выбранному
адресу. Открыть адрес в обычном браузере: должна быть игра с полосой «ТЕСТ ОК · … · клиент: —».

**Шаг 3 — режим разработки, только Web.** «Размещение» → Web → включить «Режим разработки»,
вписать тестовый адрес. **Поле URL не трогать.** Другие платформы не трогать.

**Шаг 4 — живой запуск в ОК под создателем.** Открыть `https://ok.ru/app/vk_app54767366` с
компьютера, войдя под аккаунтом создателя. Ожидание: полоса «ТЕСТ ОК · <дата> · <коммит> ·
клиент: ok». Сделать скриншот. Покупки не делать — магазина в сборке нет.

**Шаг 5 — основной адрес цел.** Открыть игру из аккаунта, который **не** администратор (или
попросить кого-то): полосы быть не должно. Во ВКонтакте с компьютера под вашим аккаунтом полоса
будет (режим разработки — для всех администраторов), это ожидаемо.

**Шаг 6 — откат.** Выключить «Режим разработки» для Web (и вернуть прежнее значение поля, если оно
было). Проверить, что в ОК снова открывается обычная игра без полосы.

## 5. Как понять результат

| Что видно в ОК под создателем | Вывод |
|---|---|
| Полоса «ТЕСТ ОК … клиент: ok» | Режим разработки в ОК **работает**: можно планировать тестовый платёжный обработчик и тестовую покупку (отдельный этап). |
| Игра без полосы | В ОК подмена для этой платформы/аккаунта не сработала. Проверить: включён ли режим именно для Web, открыто ли с компьютера, не мешает ли тестовая группа; при повторе — снова в поддержку со скриншотом. |
| Полоса, но «клиент: —» | Загрузилась тестовая сборка, но не через ОК (например, открыли во ВКонтакте) — повторить по ссылке ok.ru. |
| Ошибка загрузки | Проверить HTTPS-адрес в обычном браузере (шаг 2). |

## 6. Чего это не делает

Не включает платежи, не заполняет URL платёжных уведомлений ОК, не меняет основной URL, не
отправляет на модерацию, не публикует сборку и не пушит. Следующий шаг после подтверждённого
маркера — отдельный план тестовой покупки.
