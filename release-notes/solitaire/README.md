проверка повреждённого стека отмены и защита асинхронного автосбора.

(«Пограничье»/платежи) в выпускную ветку не переносились. Хеши исходников до/после сборки совпали.

CSS понадобился по результату iframe-проверки: при высоте iframe 1600px и окне 700px

диалоги расположены сверху и ограничены 560px/высотой окна. Кнопка возврата из коллекции перенесена наверх.

Патч записан с нулевым контекстом (`git apply --unidiff-zero`), чтобы проверка whitespace не считала строки контекста ошибками.

## Импорт без push

Из основной папки (это делает Claude вне ограничений песочницы):

```powershell
git fetch ./release-solitaire.bundle refs/heads/codex/release-solitaire:refs/heads/codex/release-solitaire
git worktree add C:/Users/Legion/Desktop/GameDev/.claude/release-wt/solitaire codex/release-solitaire
```

Коммит узнаётся командой `git -C .release-solitaire rev-parse HEAD`; точный хеш записан
в карточке «ДЛЯ CLAUDE — выпуск „Пасьянсов“ готов к проверке» основной доски.
Bundle создан как дельта к базе `3386337`; база должна уже присутствовать у импортирующего репозитория.

Для повторения проверок **из основной папки**, где находятся актуальные исходники и зависимости:

```powershell
$env:NODE_OPTIONS='--preserve-symlinks --preserve-symlinks-main'
node tools/build-release-solitaire.mjs
node node_modules/typescript/bin/tsc --noEmit
node tools/test-solitaire-release.mjs
node tools/review-solitaire-release.cjs .release-solitaire
node tools/review-solitaire-baseline.mjs .release-solitaire
node tools/verify-solitaire-package.mjs .release-solitaire
```

Сборщик пишет dist основной папки, но не обновляет release-папку автоматически: после новой сборки
её нужно синхронизировать, убрав устаревшие ассеты, и повторить сверку. Проверка/съёмка обновляет
три скриншота основной папки, затем их надо скопировать в checkout. Генерация иконок/сниппета:
`node tools/make-solitaire-store.cjs` (нужны локальные мастера).
